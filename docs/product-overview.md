# Source Mindmap App

Application desktop/local-first pour lire, comprendre, restructurer et editer des fichiers sources reels via une mindmap source-aware.

Ce dossier ne cree pas un SaaS. Il reprend seulement la structure documentaire utile du workflow `create-saas-idea` pour garder une trace exploitable plus tard :

- `docs/idea.md` - vision produit et decisions validees
- `docs/discovery.md` - contexte utilisateur, douleurs et decisions de cadrage
- `docs/prd.md` - MVP et exigences produit
- `docs/archi.md` - architecture technique cible
- `docs/marketing.md` - angles de positionnement futurs
- `docs/feed-integration.md` - relation avec l'ancien projet `notes-feed-saas`
- `docs/open-questions.md` - questions a trancher
- `docs/tasks/` - premieres taches MVP
- `docs/modules/notes-feed/` - anciens fichiers de cadrage `notes-feed-saas`, conserves comme module futur
- `PLAN.md` - lot actif et suites validees du projet
