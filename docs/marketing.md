# Source Mindmap App - Marketing Notes

## Positioning candidates

### 1. Source-aware mindmap for builders

Pour les developers, consultants et builders qui travaillent avec des agents IA, l'app transforme leurs fichiers reels en mindmap editable. Contrairement a XMind/MindNode/Heptabase, la carte reste liee aux sources.

### 2. iA Writer + MindNode for real files

Lire, structurer et reecrire des documents longs avec la clarte d'un editeur d'ecriture et la puissance visuelle d'une mindmap.

### 3. Contract and long-document editor

Rediger des contrats et documents longs avec articles, clauses, renvois automatiques et restructuration visuelle sans casser la numerotation.

### 4. Personal knowledge map over your actual files

Pas une base de donnees proprietaire. Pas une copie. Une vue vivante au-dessus de vos Markdown, docs et sources.

## Main differentiator

Les mindmaps classiques copient l'information. Cette app la relie a la source.

## Competitors / inspirations

- MindNode : experience mindmap fluide.
- iA Writer : lecture/ecriture calme.
- Essay.app : reecriture et reorganisation au niveau phrase.
- Notion : manipulation de blocs, mais sans source Markdown reelle.
- Heptabase : canvas de connaissance, mais source separee.
- XMind : mindmap puissante, mais non synchronisee avec les fichiers.

## Later SaaS angle

Le SaaS n'est pas le produit initial. Il peut devenir :

- sync cloud ;
- feed mobile / Today review ;
- Project Radar ;
- Transformation Queue ;
- review quotidienne ;
- recherche ;
- backup des maps ;
- collaboration.

`notes-feed-saas` devient donc un angle/module futur, pas un produit separe concurrent.

## Taglines

- Mindmaps for files that actually change.
- Structure your source, not a copy.
- A visual editor for your real Markdown and code copy.
- Stop redrawing your documents in XMind.
